# batana-tool UX/可用性评审报告（2026-09-20）

> 评审范围：docs/prd.md 全文 + app/ 全部源码 · 视角：单人、非工程师、现场 3 米远距操作 + 事后审核

## 一、总评

| 维度 | 分数 | 一句话 |
|---|---|---|
| 采集便利性 | 3/5 | 自动循环主干完整、默认阈值合理，但 3 米可视反馈只靠英文状态词，倒计时无视觉呈现，静音/嘈杂环境下用户"失盲" |
| 标注/修剪便利性 | 2/5 | 基本链路都在，但长素材审核没有跳关键帧/挑坏帧快捷路径，标记后不自动跳下一段，未保存修改静默丢失 |
| 单人独立完成 | 3/5 | 主流程不用第二人，但异常分支语音只覆盖人离开/通用异常，"挥了但没检测到"零反馈，ARMED 无限等待 |
| 健壮性/防呆 | 2/5 | 索引原子落盘 + rebuild + 编码回退好；相机断连无重连、磁盘满无预检、重建无 UI 入口、core 路径硬编码 |
| PRD 符合度 | 3/5 | F1–F10 全部"有东西"，但 F1/F4/F6/F7/F8/F9 均为部分实现 |

## 二、缺口清单（按优先级）

### 高优先级

- **H1 倒计时与"该做什么"无视觉呈现，状态横幅是英文术语**（state_machine.py:137-147 倒计时只走语音；widgets.py:58-74 StateBanner 显示 IDLE/READY/ARMED 原文且除 ERROR 外全白）→ 3 米外/嘈杂/静音时用户不知道现在该挥棒还是该等。改法：中文语义映射（READY→请准备、ARMED→请挥棒！、SWING→录制中、SAVING→保存中）+ 分色 + Banner 大号显示倒计时数字
- **H2 审核页标记后不跳下一段、无触发帧跳转**（review_page.py:513-519 mark 后选择丢失；trigger_idx 已存索引但 UI 未用；step 只有 ±1）→ 200 段量级审核的最大摩擦点。改法：标记后自动选中下一条待复核；加"跳到触发帧"；Shift+←/→ ±10 帧、Ctrl+Z 撤销
- **H3 未保存的骨架修正/修剪在切换素材时静默丢失**（review_page.py:275-300，_pose_dirty 标志存在但从未检查）→ 改法：load_record 入口检查脏标志，弹"保存/放弃/取消"
- **H4 已落盘误检段无法从 UI 删除**（SessionStore.delete() 已实现但 UI 无调用）→ 改法：删除按钮 + 二次确认
- **H5 相机断开无重连、崩溃重建无入口、异常语音不区分原因**（controller.py:52-56；state_machine error/recover 无人调用；store.rebuild 启动不调）→ 改法：启动静默 rebuild + 恢复提示；异常文案区分相机/存储

### 中优先级

- **M1 保存片段期间采集线程同步阻塞**（controller.py:265-279，PRD §5 要求独立 EncodeWorker）→ 每次挥棒后预览冻结 1–3s、可能掉帧。改法：Clip 入队、worker 线程消费
- **M2 骨架只跑左目且只能手动逐段触发**（review_page.py:393 写死 left）→ 改法：eye 参数下拉（左/右/双）
- **M3 "挥了但没检测到"零反馈，ARMED 无超时**（state_machine.py:150-154）→ 改法：ARMED 超时语音提示 + 能量条触发阈值刻度线
- **M4 批量导出主线程同步、无进度、无磁盘预检、core 路径硬编码个人目录**（review_page.py:523-552；export.py:29）→ 改法：磁盘预检 + QThread 导出 + core 路径入 settings
- **M5 首次使用零引导**（默认 ROI 不回显、相机源写死 0/1/2、MJPEG 无警告）→ 改法：默认 ROI 回显、未框 ROI 常显提示、MJPEG 选择弹警告

### 低优先级

- **L1 采集页无键盘快捷键**（空格=手动开始/结束、D=丢弃）；"丢弃重拍"与"手动开始"按钮紧邻误触风险
- **L2 拖动关键点无缩放辅助**（HIT_RADIUS_PX=10，小点难选中）→ 滚轮缩放/局部放大（v0.3）
- **L3 播放按真实 fps 起 QTimer 达不到 120Hz** → 提供 0.25×/0.5× 慢放档
- **L4 重复导出静默覆盖无提示**
- **L5 磁盘占用预估显示未实现**（PRD §4）
- **L6 撤销只到单点级、无重做、无快捷键**

## 四、性价比最高的 3 个改进点

1. **状态横幅中文化 + 视觉倒计时**（H1）：约 50 行，直接解决 3 米外"现在该做什么"
2. **标完自动跳下一段待复核 + 跳到触发帧**（H2）：数据现成约 30 行，砍掉审核最大摩擦
3. **未保存确认 + 删除素材按钮**（H3+H4）：后端已完工只差 UI 接线，消除两个数据丢失点

## 五、整改记录

> 整改实施于 2026-09-20（当日完成），全量测试 125 项连跑两遍全绿。

### 高优先级（全部已整改）

- **H1 ✅ 已整改**：`app/ui/widgets.py` StateBanner 状态映射中文化（IDLE→等待就位、READY→请准备、ARMED→请挥棒！、SWING→录制中、SAVING→保存中、ERROR→异常）+ 分色（IDLE/SAVING 暗灰、READY 亮白、ARMED/ERROR 强调红、SWING 红底白字）；READY 倒计时 3/2/1 大号数字由 UI 侧 QTimer 跟随 READY 起始时间显示（核心层语义未动）
- **H2 ✅ 已整改**：`app/ui/review_page.py` 标记后自动选中列表下一条待复核（`_select_next_pending`）；走带区新增「跳到触发帧」（trigger_idx 存索引时已改为段内相对帧号）；Shift+←/→ 步进 ±10 帧；Ctrl+Z 撤销快捷键
- **H3 ✅ 已整改**：load_record 入口检查 `_pose_dirty`/`_trim_dirty`（修剪脏标志本次补齐），弹「保存/放弃/取消」，取消时还原列表选择
- **H4 ✅ 已整改**：审核页左栏「删除选中素材」按钮 + 二次确认，走现成 `SessionStore.delete`
- **H5 ✅ 已整改**：MainWindow 启动静默 `store.rebuild()`，补登 >0 段时状态栏提示「已恢复 N 段素材」；异常文案按消息分类为「相机断开/存储失败/通用异常」（`app/voice.error_prompt`），语音对应拆两条新文案，抓帧线程异常接入状态机 `error()/ERROR` 态

### 中优先级（全部已整改）

- **M1 ✅ 已整改**：`_save_clip` 从抓帧线程移到 `_SaveWorker`（QThread 单消费者队列；入队时即刻提取环形缓冲帧引用防覆盖；SAVING 语义与核心层接口不变）
- **M2 ✅ 已整改**：审核页骨架目下拉（左/右/双），`_PoseWorker` 支持多目；左目沿用 pose2d.json（契约既有结构），右目分存 pose2d_right.json，切换查看目自动载入对应骨架
- **M3 ✅ 已整改**：ARMED 持续 15s 无挥棒语音提示「未检测到挥棒，请用力挥棒或使用手动开始」（UI 层 QTimer，状态机未动）；能量 MiniBar 加触发阈值刻度竖线
- **M4 ✅ 已整改**：批量导出前磁盘预检（总帧数×单目分辨率×2 目×1.2 安全系数 vs `shutil.disk_usage`，不足弹窗中止）；导出循环移到 `_ExportWorker`（QThread + 状态栏进度 i/N）；core 仓路径改为 settings 可配（`core_repo_path`，默认自动探测常见位置）
- **M5 ✅ 已整改**：检测器懒建默认 ROI 同步回显预览；未框 ROI 时采集页常显「请先在画面上框选打击区」；设置页选 MJPEG 弹「仅供冒烟，正式素材请用无压缩」警告

### 低优先级（L1/L3/L4/L5 已整改）

- **L1 ✅ 已整改**：采集页空格 = 手动开始/结束挥棒、D = 丢弃重拍；手动开始/结束按钮间距拉大，丢弃重拍与之间隔 12px
- **L3 ✅ 已整改**：审核页回放速度 0.25×/0.5×/1× 档（播放中切换即时生效）
- **L4 ✅ 已整改**：重复导出报告逐段注明「（覆盖已有导出）」
- **L5 ✅ 已整改**：设置页「预计磁盘占用」静态估算（计划段数 × 单段大小，实时刷新）
- **L2/L6 未整改**：拖动关键点缩放辅助、撤销重做增强，属 v0.3 后续范畴
